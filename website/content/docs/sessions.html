Sessions

Learn how to manage user sessions and maintain state in Suave applications.

Cookie-Based Sessions

Read request cookies with ctx.request.cookies and write them with Cookie.setCookie, both from Suave.Cookie. Building Set-Cookie headers or splitting the Cookie header by hand breaks as soon as the browser sends more than one cookie (a=1; sessionId=xyz).

Session ids must be unguessable. Take them from RandomNumberGenerator rather than Guid.NewGuid(), whose randomness is an implementation detail rather than a guarantee:

open System.Buffers.Text
open System.Security.Cryptography
open Suave
open Suave.Cookie
open Suave.Filters
open Suave.Operators
open Suave.Successful

/// 256 bits from the OS random number generator, URL-safe (43 characters).
let newSessionId () =
  RandomNumberGenerator.GetBytes 32 |> Base64Url.EncodeToString

let sessionCookie (sessionId : string) =
  { HttpCookie.createKV "sessionId" sessionId with
      secure   = true
      sameSite = Some Lax }

let app =
  choose [
    path "/set-session" >=> context (fun _ ->
      setCookie (sessionCookie (newSessionId ())) >=> OK "Session set")

    path "/get-session" >=> context (fun ctx ->
      match ctx.request.cookies |> Map.tryFind "sessionId" with
      | Some cookie -> OK (sprintf "Session id: %s" cookie.value)
      | None -> OK "No session")
  ]

HttpCookie.createKV sets path = Some "/" and httpOnly = true. Browsers only send Secure cookies over HTTPS; most make an exception for http://localhost. Base64Url needs .NET 9 or later.

Session Storage Patterns

Store session data with in-memory or database backends, keyed by the session id:

open System.Collections.Concurrent
open Suave
open Suave.Cookie
open Suave.Filters
open Suave.Operators
open Suave.Successful
open Suave.RequestErrors

// newSessionId and sessionCookie as defined above

type SessionData = { userId : int; username : string }

// In-memory session store
let sessions = ConcurrentDictionary<string, SessionData>()

let app =
  choose [
    POST >=> path "/login" >=> context (fun _ ->
      // Always issue a new id on login, never reuse one the client sent
      let sessionId = newSessionId ()
      sessions.[sessionId] <- { userId = 1; username = "john" }
      setCookie (sessionCookie sessionId) >=> OK "Session created")

    path "/profile" >=> context (fun ctx ->
      match ctx.request.cookies |> Map.tryFind "sessionId" with
      | Some cookie ->
          match sessions.TryGetValue cookie.value with
          | true, sessionData -> OK (sprintf "Session data: %A" sessionData)
          | false, _ -> UNAUTHORIZED "Invalid session"
      | None -> UNAUTHORIZED "No session")
  ]

Session Timeout

Give the cookie an expiry date. HttpCookie has no Max-Age field; expires is an absolute time. The browser treats it as a hint, so also enforce the timeout on the server (see Session Cleanup):

open System
open Suave
open Suave.Cookie
open Suave.Filters
open Suave.Operators
open Suave.Successful

// newSessionId and sessionCookie as defined above

let sessionTimeout = TimeSpan.FromMinutes 30.0

let app =
  path "/login" >=> context (fun _ ->
    let cookie =
      { sessionCookie (newSessionId ()) with
          expires = Some (DateTimeOffset.UtcNow.Add sessionTimeout) }
    setCookie cookie >=> OK "Session created with 30 minute timeout")

Secure Session Cookies

Create secure session cookies for production. SameSite = Lax keeps the cookie off cross-site subrequests and form posts while still sending it when the user follows a link to your site; use Strict if even that is not wanted:

open System
open Suave
open Suave.Cookie
open Suave.Filters
open Suave.Operators
open Suave.Successful

// newSessionId as defined above

let secureSessionCookie (sessionId : string) =
  { HttpCookie.createKV "sessionId" sessionId with
      // createKV already sets path = Some "/" and httpOnly = true
      secure   = true
      sameSite = Some Lax
      expires  = Some (DateTimeOffset.UtcNow.AddMinutes 30.0) }

let app =
  path "/secure-login" >=> context (fun _ ->
    setCookie (secureSessionCookie (newSessionId ())) >=> OK "Secure session created")

Ending a Session

Remove the server-side entry and expire the cookie with Cookie.unsetCookie:

open System
open Suave
open Suave.Cookie
open Suave.Filters
open Suave.Operators
open Suave.Successful

// sessions as in Session Storage Patterns

let logout =
  path "/logout" >=> context (fun ctx ->
    match ctx.request.cookies |> Map.tryFind "sessionId" with
    | Some cookie -> sessions.TryRemove cookie.value |> ignore
    | None -> ()
    unsetCookie "sessionId" >=> OK "Logged out")

// A cookie that was set with a narrower path...
let setAdminCookie =
  setCookie { HttpCookie.createKV "adminPrefs" "compact" with path = Some "/admin" }

// ...is only removed by an expired cookie with the same name, path and domain
let unsetAdminCookie =
  setCookie
    { HttpCookie.createKV "adminPrefs" "" with
        path    = Some "/admin"
        expires = Some DateTimeOffset.UnixEpoch }

Note: unsetCookie always sends Path=/ and no Domain. Browsers identify a cookie by name, path and domain, so a cookie set with a narrower path such as /admin (or with a domain) is not removed by it; expire it with setCookie and the same path and domain, as above.

Session Cleanup

Check the idle timeout when a session is used and remove expired sessions in the background. Keep printfn out of server code: hand the loop a logging function instead of writing to Console.

open System
open System.Collections.Concurrent
open System.Threading
open Suave
open Suave.Successful

let idleTimeout = TimeSpan.FromMinutes 30.0

// Session data and the time (UTC) the session was last used
let sessions = ConcurrentDictionary<string, obj * DateTime>()

/// Finds a live session and records that it was used now.
let tryTouch sessionId =
  match sessions.TryGetValue sessionId with
  | true, ((data, lastUsed) as current) when DateTime.UtcNow - lastUsed < idleTimeout ->
      // Fails harmlessly if another request touched it or cleanup removed it
      sessions.TryUpdate(sessionId, (data, DateTime.UtcNow), current) |> ignore
      Some data
  | _ -> None

/// Removes sessions idle for longer than idleTimeout; returns how many.
let removeExpiredSessions () =
  let cutoff = DateTime.UtcNow - idleTimeout
  sessions
  |> Seq.filter (fun kvp -> snd kvp.Value < cutoff)
  |> Seq.toList
  // Removes the entry only if it still holds the same value, i.e. it has
  // not been touched since it was found to be expired
  |> List.filter (fun kvp -> sessions.TryRemove kvp)
  |> List.length

let cleanupLoop (log : string -> unit) =
  async {
    while true do
      do! Async.Sleep (TimeSpan.FromMinutes 1.0)
      let removed = removeExpiredSessions ()
      if removed > 0 then log (sprintf "Removed %d expired sessions" removed)
  }

[<EntryPoint>]
let main argv =
  use cts = new CancellationTokenSource()
  // Pass your application's logger here; Globals.writeMessage goes to
  // Globals.messageWriter when one is set
  Async.Start (cleanupLoop Globals.writeMessage, cts.Token)

  let config = { defaultConfig with cancellationToken = cts.Token }
  startWebServer config (OK "Sessions with cleanup")
  0

Encrypted Cookie State

For small amounts of per-user state you can skip the server-side store entirely. statefulForSession from Suave.State.CookieStateStore keeps a map of values in a cookie (st), encrypted and authenticated with the server key, and HttpContext.state reads and writes it (see the cookie sessions recipe):

open Suave
open Suave.Filters
open Suave.Operators
open Suave.Successful
open Suave.State.CookieStateStore

let app =
  statefulForSession >=> choose [
    path "/visit" >=> context (fun ctx ->
      match HttpContext.state ctx with
      | Some store ->
          let visits = defaultArg (store.get "visits") 0 + 1
          store.set "visits" visits >=> OK (sprintf "Visit number %d" visits)
      | None ->
          RequestErrors.BAD_REQUEST "no state store")
  ]

The client cannot read or change the state, but it can replay an old cookie, and the server cannot revoke one. statefulForSession is stateful Session false; behind HTTPS use stateful Session true (or a MaxAge lifetime) so the cookie is marked Secure. Keep the state small: browsers limit a cookie to about 4 KB.

A stable server key

defaultConfig generates a random serverKey each time the process starts. Every state cookie, and every Suave.Authentication cookie, becomes unreadable after a restart, and instances behind a load balancer cannot read each other's cookies. In production, load a 32-byte key from configuration:

open System
open Suave

// Generate a key once and keep it in a secret store, e.g.:
//   openssl rand -base64 32
let config =
  { defaultConfig with
      serverKey = ServerKey.fromBase64 (Environment.GetEnvironmentVariable "SUAVE_SERVER_KEY") }

ServerKey.fromBase64 throws if the value is not a 32-byte key, so a missing or malformed key fails at startup. Changing the key invalidates every existing cookie, which signs all users out.

Authentication cookies

Authentication.authenticated stores a session id in the encrypted auth cookie, which Authentication.HttpContext.sessionId reads back. The cookie also records the client IP address and User-Agent of the login request, but Suave does not compare them on later requests, so the cookie is not bound to a client: anyone who obtains it is signed in until it expires. Pass secure = true behind HTTPS and prefer a short MaxAge.

CSRF Token Sessions

Protect forms with CSRF tokens in sessions:

open System.Buffers.Text
open System.Collections.Concurrent
open System.Security.Cryptography
open System.Text
open Suave
open Suave.Cookie
open Suave.Filters
open Suave.Operators
open Suave.Successful
open Suave.RequestErrors

let csrfTokens = ConcurrentDictionary<string, string>()

let generateCSRFToken sessionId =
  let token = RandomNumberGenerator.GetBytes 32 |> Base64Url.EncodeToString
  csrfTokens.[sessionId] <- token
  token

let validateCSRFToken sessionId (token : string) =
  match csrfTokens.TryGetValue sessionId with
  | true, storedToken ->
      CryptographicOperations.FixedTimeEquals(
        Encoding.UTF8.GetBytes storedToken, Encoding.UTF8.GetBytes token)
  | false, _ -> false

let sessionId (ctx : HttpContext) =
  ctx.request.cookies |> Map.tryFind "sessionId" |> Option.map (fun c -> c.value)

let app =
  choose [
    GET >=> path "/form" >=> context (fun ctx ->
      match sessionId ctx with
      | Some sid ->
          let token = generateCSRFToken sid
          OK (sprintf "<input type='hidden' name='csrf_token' value='%s'>" token)
      | None -> FORBIDDEN "No session")

    POST >=> path "/form" >=> context (fun ctx ->
      match sessionId ctx, ctx.request.formData "csrf_token" with
      | Some sid, Choice1Of2 token when validateCSRFToken sid token ->
          OK "Form submitted safely"
      | _ -> FORBIDDEN "CSRF token invalid")
  ]
