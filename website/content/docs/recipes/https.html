Recipe: HTTPS and HTTP redirect

Goal: Bind TLS and optionally force HTTPS.

open System
open System.Security.Cryptography.X509Certificates
open Suave
open Suave.Filters
open Suave.Operators
open Suave.Successful
open Suave.Redirection

let cert = X509CertificateLoader.LoadPkcs12FromFile("certificate.p12", "password")
let httpsPort = 8443
let http  = HttpBinding.createSimple HTTP "0.0.0.0" 8080
let https = HttpBinding.createSimple (HTTPS cert) "0.0.0.0" httpsPort

let redirectToSsl (allow : WebPart) : WebPart =
  context (fun c ->
    if c.request.binding.scheme.secure then allow
    else
      let authority = if httpsPort = 443 then c.request.host else sprintf "%s:%d" c.request.host httpsPort
      let query = if String.IsNullOrEmpty c.request.rawQuery then "" else "?" + c.request.rawQuery
      redirect (sprintf "https://%s%s%s" authority c.request.rawPath query))

let cfg = { defaultConfig with bindings = [ http; https ] }
let app = redirectToSsl (OK "Secure hello")

startWebServer cfg app

The redirect keeps the path and query string as the client sent them, so http://example.com:8080/search?q=a%20b goes to https://example.com:8443/search?q=a%20b. redirect answers with 302 Found; use Redirection.moved_permanently for a 301 once the setup is final.

Load the certificate with X509CertificateLoader; the X509Certificate2 file constructors are obsolete since .NET 9. Keep the password out of source code, for example in an environment variable.

Behind nginx, TLS usually ends at the proxy and every request reaches Suave over HTTP, so check the X-Forwarded-Proto header (c.request.header "x-forwarded-proto") instead of scheme.secure, or let nginx do the redirect. See Bindings and Deployment.
